# David's landing page

A small first release built with plain HTML and CSS. No installation or build step is needed. Open `dist/index.html` in a browser.

## What to learn first

- `dist/index.html` defines the content and its meaning: header, main sections, footer.
- `dist/styles.css` defines how that content looks. The numbered comments divide it into four manageable parts.
- The media query at the bottom changes the layout on smaller screens.
- `dist/favicon.svg` is the small DG icon used by browser tabs.

## Your first exercise

Change one sentence in the bio and the `--accent` color in CSS. Refresh the page and explain which file controls each change. Ask AI to review your edit and explain any issues before accepting suggestions.

## Connect the real résumé

The current résumé link navigates to an honest placeholder section. Once you have your PDF, save it as `dist/resume.pdf`, change the button's href to `resume.pdf`, and update or remove the placeholder section. Do not publish a fabricated résumé.

## Grow slowly

The background uses the three uploaded originals in `dist/photos/`. An SVG filter maps grayscale brightness into black and green; CSS controls opacity and fades. `dist/slideshow.js` randomly selects the starting image and a different image every eight seconds. Visitors can pause it, and reduced-motion preferences start it paused.

Finish the résumé link and review the bio first. A learning-log entry can be a later change. Keep each change small enough to describe and review.
